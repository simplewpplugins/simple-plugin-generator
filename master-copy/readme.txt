== Installation ==

**This section describes how to install the plugin and get it working**

= AUTOMATIC INSTALLATION (EASIEST WAY) =

To do an automatic install of [{(plugin_name)}], log in to your WordPress dashboard, navigate to the Plugins menu and click
Add New.
In the search field type "[{(plugin_name)}]" by Simple Plugins. Once you have found it you can install it by simply clicking
"Install Now" and then "Activate".

= MANUAL INSTALLATION =

**Uploading in WordPress Dashboard**

* Download *[{(plugin_slug)}].zip*
* Navigate to the *'Add New'* in the plugins dashboard
* Navigate to the *'Upload'* area
* Select *[{(plugin_slug)}].zip* from your computer
* Click *'Install Now'*
* Activate the plugin in the Plugin dashboard

**Using FTP**

* Download *[{(plugin_slug)}].zip*
* Extract the *[{(plugin_slug)}]* directory to your computer
* Upload the *[{(plugin_slug)}]* directory to the */wp-content/plugins/* directory
* Activate the plugin in the Plugin dashboard

The WordPress codex contains <a href="https://codex.wordpress.org/Managing_Plugins#Manual_Plugin_Installation">instructions</a> on how to install a WordPress plugin.
